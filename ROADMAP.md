# Roadmap

These are planned directions, **not shipped features**. Priorities depend on contributions and real-world test cases.

- [ ] More robust character-layer decomposition and guided reconstruction of flattened SVGs.
- [ ] Explicit pivot/origin debugging overlay and frame-diff regression tests.
- [ ] Improved support for masks, compound paths, and skeletal motion.
- [ ] Multi-character test fixtures with redistribution-safe source artwork.
- [ ] Renderer-tested Lottie/Bodymovin export for a supported subset of SVG/CSS motions.
- [ ] Browser performance budgets, frame stepping, and accessibility scenarios.
- [ ] Packaging/release automation and versioned examples.

For feature requests, please describe the target mascot, the missing capability, and expected browser behavior.
