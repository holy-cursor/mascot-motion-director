# Changelog

Notable changes are documented here. The project follows semantic versioning where practical.

## [1.0.0] - 2026-10-22

- Initial public-ready Agent Skill instructions and prompt-only fallback.
- SVG structure inspection, motion-plan schema and 12-principle audit.
- Transform-preserving SVG animation compilation and website component.
- Robot mascot demonstration, unit tests and optional Chromium browser checks.
- Safe-loading restrictions and explicit semantic-reconstruction workflow.

### Known limitations

- Vision-based identification and reconstruction require an AI agent / designer.
- Lottie JSON export and universal auto-rigging are not included.
